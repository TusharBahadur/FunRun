Flat illustration motifs cut from the brand palette, for empty states, marketing and gift decoration. Colours are fixed in the files (rose `#e23b54`, rose-deep `#bf2840`, blush `#f6d3cf`, gold `#f6b73c`, ink `#1b1215`, paper `#fbf8f3`, line `#e3d8ca`).

- `heart.svg`: love, favourites, the thank-you moment.
- `candle.svg`: birthdays and wishes; striped like the number candles in gifts.
- `cake.svg`: birthday templates and the Candle / Make a Wish / The Party tiers.
- `wax-seal.svg`: sending, sealed, "opens at midnight"; the brand's core metaphor.
- `polaroid.svg`: memories and photos.
- `sparkle.svg`: small celebration accents. Use at most three per view.

Use them at 48px and up; below that use a Lucide icon instead.
