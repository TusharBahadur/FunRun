The TyniTales logo: the wordmark, or the monogram where the wordmark won't fit.

**Provide** nothing but a background from the approved list. In the web app use the `<Logo>` component (`src/components/ui/logo.tsx`), which sets the name in `wordmark` with a rose full stop; everywhere else use the `Logos` SVGs.

- Wordmark (ink) on `cream`, `paper`, `blush` and light occasion grounds; wordmark (cream) on `ink`, `wine` and dark grounds.
- Monogram (rose tile) by default; monogram (ink tile) on `rose` or busy images.
- Clear space: the height of the lowercase *a*. Minimum: 72px wide (wordmark), 16px (monogram).
- Don't recolour the letters, drop or recolour the full stop, put the wordmark on `rose`, stretch it, outline it or add effects.
