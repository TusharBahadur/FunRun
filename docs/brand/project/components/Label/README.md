Small uppercase labels set in `label` (IBM Plex Mono 12px): eyebrows above headlines, tags, counters and step numbers.

**Provide** two to six words. Source: `Eyebrow` in `src/components/ui/eyebrow.tsx` and the `type-label` utility.

- Eyebrow: "(02) — How it works": a section number in brackets only when sections really are a sequence.
- Text colour `muted` on `cream`/`paper`; step numbers in `rose-deep` (rose is too light at 12px).
- Never above 16px, never more than one line, never for sentences.
